# Path To Coding

**Personalized Programming Learning & Career Guidance System** — frontend prototype (first project update).

Assess Skills → Understand Skill Gaps → Choose Career Goal → View Learning Roadmap

Built with Next.js (App Router), React, TypeScript, Tailwind CSS and Lucide icons. All data is fictional sample data stored in `src/data/mockData.ts`; there is no backend, database or login.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000
